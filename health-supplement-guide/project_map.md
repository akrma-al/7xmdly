# دليلي الدوائي - Smart Medicine Guide

## نظرة عامة

تطبيق ويب خيري عربي لتحليل الأدوية والمكملات الغذائية واكتشاف التفاعلات الدوائية وإرشاد المرضى. يعتمد على نموذج Gemini للذكاء الاصطناعي لتحليل صور الأدوية وتقديم معلومات صحية شاملة بالعربية.

**المستخدمون المستهدفون:** المرضى، الباحثون عن معلومات صحية، مستخدمو المكملات الغذائية.

---

## رحلة المستخدم

```
1. تسجيل الدخول/إنشاء حساب → 2. لوحة التحكم (مكملاتي) → 3. إضافة/إزالة مكملات
                                            ↓
4. فحص التفاعلات → 5. عرض التحذيرات والتعارضات
                                            ↓
6. الجدول اليومي → 7. توصيات الجرعات (صباحاً/قبل التمرين/بعد التمرين/قبل النوم)
                                            ↓
8. تحليل الدواء بالصورة → 9. نتائج التحليل الشاملة
```

```bash
python app.py
```

## تكامل الذكاء الاصطناعي (Gemini)

يستخدم التطبيق نموذج Gemini 1.5 Flash من Google للتحليل:

```bash
pip install google-genai Pillow
export GEMINI_API_KEY="your-key-here"
export GEMINI_MODEL="gemini-1.5-flash"
```

### الميزات المدعومة بالذكاء الاصطناعي:
1. **تحليل صور الأدوية** - رفع صورة لعلبة الدواء وتحليلها تلقائياً
2. **تحليل التفاعلات الدوائية** - فحص التفاعلات بين المكملات باستخدام Gemini
3. **تحليل شامل بالعربية** - جميع النتائج باللغة العربية مع تحذيرات مخصصة
